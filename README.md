## single for mix-space

<img width="3018" height="1968" alt="image" src="https://github.com/user-attachments/assets/f81ff401-5236-4896-b521-75477fc2dd87" />


基于保罗的 Single 主题做的移植 Mix-space 的尝试，在原来的基础上独立实现增加 mx 的特性。

- 评论
- 日记
- 友链（非公开内容实现）
- Pages
- Markdown 扩展，LinkCard
- RSS：/feed & /atom.xml

替换 footer “时光机” 为 “日记”、“最近评论” 为 “站点 Pages”


不要用于生产环境，目前来说只是个玩具，并没有明确完善他。

> [!IMPORTANT]
> - **mx-Single 是 [Single](https://github.com/Dreamer-Paul/Single) 的社区分支**，请勿向原作者 (@Dreamer-Paul) 报告本项目的 Issue。
>
> - **版本要求**：目前 Single **仅支持 Mix Space Core 版本 == 12.x (API v2)**。
